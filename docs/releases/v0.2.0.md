# 🎉 cnki-downloader v0.2.0

CNKI 知网论文检索、详情补全、作者编码获取与 PDF / CAJ 下载工具。本次更新完善了 PyQt6 桌面工作台，并改进批量下载策略、后台保存和作者链接恢复流程。

## 安装

### Windows 桌面安装版

下载 [CNKI-Paper-Assistant-0.2.0-Setup-x64.msi](https://github.com/ZHOUoutlook/cnki_downloader/releases/download/v0.2.0/CNKI-Paper-Assistant-0.2.0-Setup-x64.msi)，双击安装即可使用，无需单独安装 Python。

- 支持 Windows 10 / 11 64 位，安装界面可编辑安装路径或浏览选择其他磁盘和目录。
- 默认安装到当前用户目录，支持开始菜单、可选桌面快捷方式及卸载。
- 应用界面为中文，MSI 安装界面为英文；当前安装包未进行数字签名。
- 用户数据默认保存在“文档/CNKI论文助手/output”，卸载时保留。

### Python 安装版

下载本页附件中的 wheel 后安装：

```bash
# 核心功能（search / detail / author / download）
pip install --upgrade cnki_downloader-0.2.0-py3-none-any.whl

# 同时安装 PyQt6 桌面 GUI
pip install --upgrade "cnki_downloader-0.2.0-py3-none-any.whl[gui]"
```

也可以在源码目录中安装：

```bash
pip install .              # 核心功能
pip install ".[gui]"       # + PyQt6 桌面 GUI
pip install -e ".[dev]"    # 开发模式（含测试依赖）
```

## 快速上手

```bash
# 启动桌面工作台
cnki-gui
# 或：python -m cnki_downloader.gui_app

# 搜索期刊论文（匿名访问，无需校园网）
cnki search --journal "金融研究" --start-page 2 --pages 5

# 补全详情（DOI、摘要、关键词、作者单位等）
cnki detail --input output/金融研究.json

# 获取作者 au-code（可选）
cnki author --input output/金融研究.json

# 批量下载 PDF / CAJ（需知网授权 IP）
cnki download --input output/金融研究.json
```

GUI 中可直接导入已有 JSON，依次完成检索、详情补全、作者编码获取和下载；支持筛选、排序、选择处理范围、暂停与停止任务。

## 作为库使用

```python
from cnki_downloader import CNKIAuth, CNKISearcher

auth = CNKIAuth()
session = auth.anonymous_login()
try:
    searcher = CNKISearcher(session)
    papers = searcher.search_by_journal_all_pages(
        "金融研究", max_pages=5, start_page=1
    )
    for paper in papers:
        print(paper.title, paper.source)
finally:
    session.close()
```

## 主要变更

### 桌面工作台

- 完整接入检索、详情补全、作者编码和批量下载流程，新增 `cnki-gui` 启动入口。
- 文献列表支持分页、标题／作者／来源搜索、状态筛选、排序、多选和详情查看；列表展示来源期刊。
- 侧栏宽度、列表与日志的高度可拖动调整，较小窗口下自动换行和滚动，并记住布局；收起日志时锁定上下分隔条。
- 下载日志精简为统计、单篇进度和结果，保留异常与重试提示；支持将当前日志导出为 TXT。
- 新增打开下载目录和 GitHub 项目主页入口；连接检查分别显示匿名访问与 IP 授权状态。

### 下载策略与状态校验

- GUI 下载前按保存目录中的实际 PDF / CAJ 核验状态，不依赖 JSON 原有的下载标记或旧路径；校验结果先批量写回 JSON。
- 对有详情链接且尚无本地文件的非视频文献生成下载队列，筛选后应用数量上限，再随机打乱下载顺序。
- GUI 与 CLI 共用每 30 篇更新会话的间隔；还有剩余任务时清理 cookies、重新进行 IP 授权登录，并额外随机等待后继续。
- 保留可配置的随机请求间隔和失败重试；重新登录后同步更新下载与链接刷新使用的会话，失败时 GUI 停止后续请求并保留进度。

### 数据保存与稳定性

- 修复详情补全和作者编码任务因在界面线程复制、保存整库而卡顿的问题，改为后台保存并合并界面刷新。
- 搜索在同目录临时 JSON 中进行增量合并和历史去重，正常完成后替换正式文件；中断时保留恢复文件。
- 工作文件采用原子写入，保留自定义字段，并对 Windows 短暂文件占用进行重试。
- 修复本地路径清空后又被原始记录带回的问题；保存失败时保留内存结果并停止后续请求。

### 详情与作者编码

- 搜索、详情补全和作者编码获取使用匿名会话，下载单独进行知网 IP 授权。
- 改进作者主页链接过期和验证后的恢复流程，保留已有作者编码，避免无效请求反复继续。
- 完善搜索结果增量合并、历史去重和详情保留逻辑。

### 文档与验证

- 新增 Windows MSI 安装包、可选 Inno Setup 构建配置和安装路径／快捷方式测试，提供无需 Python 的桌面安装方式。
- 更新安装、CLI、GUI、下载策略和数据保存说明。
- 完整回归测试 **154 项通过**，覆盖后台保存、文件占用、任务停止、随机队列、定期重新登录、状态同步、自适应布局和 Windows 安装包；网络请求使用测试替身。

## 项目结构

```text
src/cnki_downloader/
├── main.py                 # CLI 入口
├── gui_app.py              # GUI 入口
├── config.py               # 请求、超时和会话更新间隔
├── core/                   # 认证、检索、解析、详情与作者编码
├── downloaders/            # PDF / CAJ 下载与链接刷新
├── models/paper.py         # Paper / Author 数据模型
├── gui/                    # 桌面界面、后台任务、工作文件与日志
└── utils/                  # JSON 读写、文件名处理等
```

## 系统要求

- Windows MSI 安装版：Windows 10 / 11 64 位，无需单独安装 Python。
- Python 安装版：Python ≥ 3.9；GUI 需安装 `[gui]` 可选依赖（PyQt6 ≥ 6.5）。
- 搜索、详情与作者编码：匿名会话即可，无需校园网。
- 下载：需知网授权 IP（如校园网）。
- 本次提供 Windows MSI 安装包、wheel、源码压缩包及 SHA256 校验文件。
