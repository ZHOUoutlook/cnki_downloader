# 🎉 cnki-downloader v0.1.0

CNKI 知网论文检索、详情获取与 PDF 下载工具，现可作为标准 Python 包安装使用。

## 安装

```bash
pip install .              # 核心功能（search / detail / download）
pip install ".[gui]"       # + PyQt6 桌面 GUI
pip install -e ".[dev]"    # 开发模式（含 pytest 等测试依赖）
```

## 快速上手

```bash
# 搜索期刊论文（多页，从第 2 页起）
cnki search --journal "金融研究" --start-page 2 --pages 50

# 补全详情（DOI、摘要、关键词、作者单位等）
cnki detail --input output/金融研究.json

# 批量下载 PDF
cnki download --input output/金融研究.json
```

## 作为库使用

```python
from cnki_downloader import CNKIAuth, CNKISearcher

auth = CNKIAuth()
session = auth.ip_login()          # 校园网 IP 认证
searcher = CNKISearcher(session)
papers = searcher.search_by_journal_all_pages(
    "金融研究", max_pages=10, start_page=1
)
for p in papers:
    print(p.title, p.source)
```

## 主要变更

### 架构重构

- 迁移至 `src/` 标准包布局，支持 `pip install .` 直接安装
- 新增 `pyproject.toml` 打包配置（setuptools 构建后端）
- 注册 `cnki` CLI 入口点（`[project.scripts]`）

### 新增模块

- `core/pagination.py`：`build_warmup_pages()` 独立翻页预热序列函数
- `upload.py`：文献上传占位模块（内部工具不随包分发）
- `tests/test_pagination.py`：翻页序列单元测试（3 项全部通过）

### Bug 修复

- 修复 `start_page > 1` 时预热序列未从第 1 页获取初始 `hidTurnPage` 令牌的问题
  - 正确策略：`1 → 9 → 13 → 17 → ...（步长 4）→ start_page`
- 修复 `pyproject.toml` 中重复 `[tool.pytest.ini_options]` 表导致 TOML 解析失败

### 依赖优化

- `PyQt6` 从核心依赖移至 `[gui]` 可选依赖，核心库安装不再强制要求 GUI 组件
- 核心依赖仅 `requests` + `beautifulsoup4`

### 文档与工程

- 更新 `README.md`（项目结构、安装方式、CLI/GUI/库用法）
- 新增 `.gitignore`（覆盖构建产物、虚拟环境、IDE 配置、运行时数据）
- 新增 `LICENSE`（MIT）
- 新增 `requirements-gui.txt`、`requirements-dev.txt` 分场景依赖文件

## 项目结构

```
src/cnki_downloader/
├── main.py              # CLI 入口
├── gui_app.py           # GUI 入口
├── config.py            # API 端点、请求头、超时配置
├── core/
│   ├── auth.py          # IP 登录 / 匿名会话
│   ├── search.py        # 期刊/标题搜索、多页翻页
│   ├── parser.py        # 检索结果 & 详情页 HTML 解析
│   └── pagination.py    # 翻页预热序列
├── downloaders/
│   ├── base.py          # 下载器基类
│   └── pdf_downloader.py  # PDF/CAJ 下载（过期链接自动刷新）
├── models/paper.py      # Paper / Author 数据类
├── gui/                 # PyQt6 桌面界面（可选）
└── utils/file_utils.py  # JSON 读写、文件名清理
```

## 系统要求

- Python ≥ 3.9
- 搜索：匿名会话即可（无需登录）
- 详情/下载：需知网授权 IP（如校园网）
